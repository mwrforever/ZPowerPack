01展示位置：桌面端中的三个插入点

主选为「位置 A」：左侧活动栏新增入口，点开即整幅宽视图区（app-scope 扩展视图，可与会话区并排或切换）；「位置 B」为会话顶部的常驻速览条，依赖 slots 通道可用（第一天验证）；「位置 C」为兜底形态：会话内 Gen UI 卡片，刷新由命令触发。

app-scope 扩展视图，独立于会话流。适合整幅看板：额度卡片、七组图表一屏铺开。能力探测通过即落地；桌面端更新后探测失败自动落到位置 C。

位置 B · 会话速览条 待验证

宽度 340px，只放两样东西：额度微缩条 + 实时速率数字。盯盘时不离开会话。依赖 extension 的 slots 通道，第一天验证确认后保留，否则不做。

位置 C · 会话内 Gen UI 兜底

命令 /zpowerpack:dashboard 生成快照 HTML 内联渲染，数据时刻标注，刷新重新生成。保证任何构建下可用。

05组件操作与交互规范（实现依据）

以下清单与设计稿同步生效，Plan 2 的视图实现任务按此验收。

额度卡片
  • 展开/收起：点击卡片主体切换模型下钻区（仅窗口条+footer 为可点区），Enter 同效；同时只展开一张
  • 窗口条语义：满 60% 转黄、85% 转红（颜色 + 文案双信号，不只靠颜色）
  • 重置倒计时：footer 常显；official 来源显示精确余量，本地估算来源显示「你已配置」，未证实来源给出「配置分母」按钮
  • qwen 未接入态固定 CTA：跳 zcode provider 设置
实时速率区
  • 三态徽标 live / held / idle 语义见状态样张；held 时数字定格不闪动，仅徽标与数据时刻变化
  • 按模型行：点击行 → 高亮「模型吞吐对比」图中对应条形并短暂呼吸一次（一次状态确认动效，不循环）
  • 数值更新：tabular-nums 等宽，数字变化不位移布局；副行（60s 产出）同步刷新
  • 口径说明常驻小字，鼠标悬停可展开完整公式
图表通用
  • 悬停：十字参考线 + 数值 tooltip（时间、值、样本数）；离开即消失，不残留
  • 时间范围（今日/7 日/30 日）：仅作用于历史五图，实时速率与额度窗口不受影响；切换后图内标注同步（如「今日」pill）
  • 每张图有 aria-label 文本替代；色盲下靠明度阶梯与形状（实心/虚线）区分系列
  • 空数据图显示引导文案而非空白；错误显示「重试」与数据时刻
导航与刷新
  • 锚点条：粘性吸顶，滚动跟随高亮当前分区；键盘 Tab 可达，焦点环 3:1 对比
  • 数据时刻：顶栏常显；held/idle 时它是最重要的信息，视觉权重高于刷新图标
  • 设置入口：窗口规则覆盖、分母配置、备份目录（迁移向导共用一份插件配置）
  • 速览条所有交互同款语义，点击直达宽面板对应位置
令牌对照：本稿 CSS 变量 ↔ plugin-sandbox 桌面主题变量（--accent = interactive-orange 238 134 12，canvas/fg/border 系按桌面深色主题）。嵌入实现时优先读宿主变量，缺失时用本稿默认值。图表配色为六色系列（--chart-1..6），与额度/状态语义色（success/warn/danger）互不侵占。
